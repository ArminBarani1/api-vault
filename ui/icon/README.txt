logo.webp   = logo shown inside the app (replace to change)
author.webp = developer picture shown in Settings > About (also supported: author.png).
              If missing, the app loads https://xorbit.ir/up/d/71688113 and finally falls back to initials.
icon.png / icon.ico = executable icon. To regenerate all icon sizes:  cargo tauri icon ui/icon/icon.png
