## معرفی پروژه

**API Vault** یک برنامه‌ی دسکتاپ سبک برای ذخیره و مدیریت تنظیمات API هوش مصنوعی و گفت‌وگو با مدل‌های انتخابی از یک محیط واحد است. این برنامه با **Rust و Tauri 2** ساخته شده و از رابط کاربری **فارسی (راست‌چین) و انگلیسی** پشتیبانی می‌کند.

تنظیمات API و تاریخچه‌ی چت در یک انبار محلیِ رمزنگاری‌شده نگهداری می‌شوند. هنگام آزمایش اتصال یا ارسال پیام در چت، درخواست لازم به نشانی API انتخاب‌شده توسط خودت ارسال می‌شود.

## امکانات اصلی

- **انبار رمزنگاری‌شده:** محافظت از اطلاعات با **ChaCha20-Poly1305** و استفاده از کلید مشتق‌شده از پین یا رمز عبور با **Argon2id**.
- **حالت‌های قفل:** انتخاب پین، رمز عبور یا حالت بدون قفل؛ تنظیم زمان قفل خودکار و امکان قفل‌شدن برنامه هنگام مخفی‌شدن.
- **پشتیبانی از سرویس‌ها:** قالب‌های آماده برای OpenAI، Google Gemini، Anthropic، OpenRouter، Groq و Mistral، به‌علاوه‌ی endpointهای سفارشی سازگار با OpenAI.
- **مدیریت APIها:** ثبت نام دلخواه، سرویس‌دهنده، مدل، آدرس endpoint، کلید و یادداشت؛ نمایش یا مخفی‌کردن کلید، کپی اطلاعات، علاقه‌مندی و تست اتصال یک یا همه‌ی APIها.
- **چت هوش مصنوعی:** گفت‌وگو با API ذخیره‌شده، پیوست تصویر و فایل متنی/کدی پشتیبانی‌شده و نگهداری تاریخچه‌ی گفت‌وگوها.
- **ابزارهای چت:** سنجاق‌کردن، تغییر نام یا حذف گفت‌وگوها؛ نمایش Markdown، لینک‌ها و بلوک‌های کد، به‌همراه گزینه‌های کپی در بخش‌های مربوط.
- **خروجی PDF:** چاپ یا ذخیره‌ی اطلاعات API به‌صورت PDF، امکان مخفی‌کردن کلیدها و درخواست تأیید اضافی برای خروجی کلیدهای کامل وقتی برنامه قفل دارد.
- **رابط کاربری قابل تنظیم:** ظاهر شیشه‌ای با سطح‌های مختلف جلوه برای عملکرد بهتر، صفحه‌ی چت ساده یا شیشه‌ای، تم روشن/تاریک/هماهنگ با سیستم، پس‌زمینه‌ی دلخواه و زبان فارسی/انگلیسی.
- **قابلیت‌های دسکتاپ:** پشتیبانی از System Tray، جلوگیری از اجرای هم‌زمان چند نمونه و امکان پاک‌شدن کلیپ‌بورد ۳۰ ثانیه پس از کپی کلید API.

## دانلود و نصب

آخرین بسته‌ها در بخش **[Releases گیت‌هاب](../../releases)** منتشر می‌شوند.

| سیستم‌عامل | فایل | توضیح |
| --- | --- | --- |
| ویندوز | `API Vault_*_x64-setup.exe` | نصب‌کننده |
| ویندوز | `API-Vault-portable.exe` | نسخه‌ی قابل اجرا بدون نصب |
| لینوکس | `.deb` | مناسب Debian و Ubuntu |
| لینوکس | `.AppImage` | پیش از اجرا، مجوز اجرا بده: `chmod +x <file>` |
| مک (Apple Silicon) | `API-Vault-macos-arm64.dmg` | برای مک‌های سری M اپل |
| مک (Intel) | `API-Vault-macos-x64.dmg` | برای مک‌های دارای پردازنده‌ی Intel |

ممکن است ویندوز به‌دلیل امضانشدن دیجیتالی فایل، هشدار Microsoft Defender SmartScreen نشان دهد. بسته‌های macOS نیز فعلاً با گواهی Apple Developer امضا و notarize نشده‌اند و ممکن است هشدار امنیتی نمایش داده شود. فقط نرم‌افزاری را اجرا کن که به منبع آن اعتماد داری و از صفحه‌ی رسمی انتشار پروژه دریافتش کرده‌ای.

> **اگر هنوز نسخه‌ای منتشر نشده:** می‌توانی از تب **Actions** گردش‌کار ساخت را دستی اجرا کنی. اجرای دستی فایل‌های خروجی را به‌عنوان Artifact در اختیارت قرار می‌دهد؛ با ارسال تگ نسخه (`v*`) علاوه بر ساخت، GitHub Release نیز منتشر می‌شود.

## ساخت و اجرای پروژه از سورس

### پیش‌نیازها

- نصب [Rust](https://rustup.rs/)
- نصب ابزار Tauri CLI نسخه‌ی ۲:
  ```bash
  cargo install tauri-cli --version "^2" --locked
  ```
- **ویندوز:** Visual Studio Build Tools همراه با گزینه‌ی **Desktop development with C++**. معمولاً WebView2 در ویندوز ۱۰ و ۱۱ موجود است.
- **لینوکس (Debian/Ubuntu):**
  ```bash
  sudo apt-get update
  sudo apt-get install -y build-essential curl wget file libssl-dev libxdo-dev libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev
  ```

### اجرای توسعه‌ای

```bash
# YOUR_GITHUB_USERNAME را با نام کاربری گیت‌هابت جایگزین کن
git clone https://github.com/YOUR_GITHUB_USERNAME/api-vault.git
cd api-vault

cargo tauri dev
```

### ساخت نسخه‌ی نهایی

```bash
# نصب‌کننده‌ی ویندوز
cargo tauri build --bundles nsis

# بسته‌های لینوکس (این دستور را در محیط سازگار لینوکس اجرا کن)
cargo tauri build --bundles deb,appimage

# فایل نصب مک (این دستور را روی macOS اجرا کن)
cargo tauri build --bundles dmg
```

خروجی ساخت در `src-tauri/target/release/` قرار می‌گیرد. فایل‌های بسته‌بندی‌شده را در زیرپوشه‌ی `src-tauri/target/release/bundle/` پیدا می‌کنی.

## محل ذخیره‌سازی و نکات امنیتی

- **ویندوز:** `%APPDATA%\com.apivault.app\vault.bin`
- **لینوکس:** `~/.local/share/com.apivault.app/vault.bin`
- تاریخچه‌ی گفت‌وگوها نیز داخل همان انبار رمزنگاری‌شده قرار می‌گیرد.
- در حالت **بدون قفل**، کلید رمزنگاری در فایل `vault.key` کنار انبار ذخیره می‌شود؛ این حالت برای راحتی است و در برابر فردی که به حساب کاربری و فایل‌های دستگاه دسترسی دارد، محافظت معناداری ایجاد نمی‌کند.
- اگر پین یا رمز عبورت را فراموش کنی، برنامه نمی‌تواند اطلاعات رمزنگاری‌شده را بازیابی کند. اطلاعات ورود را در جای امن نگه دار.
- هنگام استفاده از چت یا تست اتصال، کلید API و/یا محتوای پیام به endpoint انتخاب‌شده ارسال می‌شود. سیاست‌های حریم خصوصی و نگهداری اطلاعات آن سرویس‌دهنده بر این درخواست‌ها اعمال می‌شود.

برای گزارش آسیب‌پذیری امنیتی، راهنمای [SECURITY.md](SECURITY.md) را بخوان و جزئیات حساس را در Issue عمومی منتشر نکن.

## شخصی‌سازی

- پس‌زمینه‌ی پیش‌فرض: `ui/png/web.webp`
- آیکون‌های سرویس‌دهنده‌ها: `ui/ico/`
- لوگو و آیکون برنامه: `ui/icon/`
- فونت فارسی اختیاری: راهنمای `ui/fonts/README.txt` را ببین.
- برای اصلاح پیوند مخزن که در بخش **تنظیمات ← درباره‌ی برنامه** نمایش داده می‌شود، مقدار `APP.repo` را نزدیک ابتدای `ui/index.html` تغییر بده.
